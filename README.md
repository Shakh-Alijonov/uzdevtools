# 🛠️ UzDevTools

**Free online tools for developers, creators, and everyday tasks.**

UzDevTools is a collection of useful online tools designed to make everyday tasks easier. Convert files, edit images, format text, generate useful data, and more — all in one place.

🌐 **Website:** https://shakh-alijonov.github.io/uzdevtools/

---

## ✨ Features

- 🖼️ **Image Tools** — Compress, convert, resize, and enhance images.
- 📄 **PDF Tools** — Merge, split, and convert PDF files.
- 💻 **Developer Tools** — Useful utilities for coding and development.
- 📝 **Text Tools** — Format, analyze, and transform text.
- 🔄 **Converters** — Convert various formats quickly and easily.
- 🧮 **Calculators** — Handy calculators for everyday use.
- 🎨 **Generators** — Create useful data and digital assets.
- ⭐ **Favorites** — Save your frequently used tools.
- 🕘 **Recently Used** — Quickly access your recent tools.
- 🌍 **Multilingual Interface** — English, Russian, and Uzbek.

---

## 🔒 Privacy

UzDevTools aims to make tools simple and accessible.

Whenever possible, file processing happens directly in your browser, so files don't need to be uploaded to a server.
